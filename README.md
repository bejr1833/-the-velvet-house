# The Velvet House — Café & Eatery

Premium React + Vite frontend demo built from the seven-page menu supplied for the café.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Configure before presenting or publishing

1. In `src/App.jsx`, replace `WA_NUMBER = '91XXXXXXXXXX'` with the café's WhatsApp number, including country code and without plus sign or spaces.
2. Replace the placeholder address, opening hours, phone number and social links with details confirmed by the owner.
3. Ask the owner to verify every menu spelling, price, variant, availability and dietary label.

## Current demo functionality

- Responsive premium emerald-green, antique-gold and cream design.
- Menu categories, search and item filters.
- Add items to a cart and change quantities.
- Checkout form preview.
- WhatsApp order link after configuring the number.

## Important limitations

This is a frontend prototype. It has no database, admin dashboard, order management, delivery integration or payment gateway. The checkout form is only a preview and does not send an order or collect payment. A production ordering system needs a secure backend and payment integration.

Menu text and prices were transcribed from the café menu supplied for this prototype. Verify with the café before going live.
